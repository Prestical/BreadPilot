# RP2350: reference document

The RP2350 datasheet (1371 pages, about 11 MB) is **not in this repository** because of its size.
Download it from the link into this folder and compare the checksum. The GPIO current facts in
`data/boards/pico-2-w.json` (`electrical.gpioCurrent`) cite it by file name and PDF page; it is kept
out of the documentation search by `.ragignore`.
